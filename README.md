# MIR4 Boss Timer

Projeto pronto para GitHub Pages.

## Como publicar

1.  Crie um repositório.
2.  Envie o arquivo `index.html`.
3.  Envie o arquivo `.nojekyll`.
4.  Em **Settings \> Pages**, escolha a branch `main` e a pasta
    `/ (root)`.

Não há dependências externas de CSS ou JavaScript locais: tudo está
embutido no `index.html`.
